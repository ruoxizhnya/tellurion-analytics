# 0001 · 纯函数只读

- **状态**：已裁决（来源：ADR-D21 / analytics-service-design.md §3、§4）
- **场景**：分析结果最容易被质疑的就是"为什么这次和上次不一样"。一旦分析里读了时钟、读了随机、或者顺手改了上游数据，同一份回测结果就会算出两份不同的报告，且无法解释。
- **决策**：① 只读上游（不写任何别人的表）；② 同一输入必须同一输出：不读系统时钟、不读系统随机，蒙特卡洛 `seed` 必填；③ POST 只表示"提交计算"，不是"改变状态"；④ 重计算走异步 job。
- **理由**："可复现"是分析服务的唯一价值。放弃它换来的性能提升没有意义 —— 一份算得快但无法复现的报告，在复盘时等于零。
- **代价 / 后果**：① 蒙特卡洛必须由调用方给种子（多一步交互）；② 异步 job 带来状态机与轮询复杂度；③ 不能"顺手"修上游数据，遇到脏数据只能报错。
- **替代关系**：无（本仓首条）
